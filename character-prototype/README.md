## 真实交付格式

preview 是可编辑自定义2.5D网格工程：原图纹理、人物黑白遮罩、背景补绘、mesh.json、顶点变形和物理计算。不是Cubism人物工程，不是重建3D。人物颜色采样原图，原图副本SHA-256与保留的源文件一致。

probe 是Cubism FREE制作通路探针：单层原图PSD、真实保存的.cmo3和导出的.moc3/.model3.json/贴图，已在独立Viewer实际重载显示。它没有转向和胸部物理，不能把它作为完成的人物模型。
