## 下一次具体从哪里开工

### 有手机反馈时

1. 先确认安装版本，防止拿旧APK的画面对照新源码。
2. 区分构图问题和运动问题：默认先用人物大小90%、上下位置10%；背部被裁就调小，头部被裁就下移。若滑杆不足以解决，再结合Surface/visible/offset/zoom记录改映射。
3. 分别测试：慢转并保持、快转反向、前后推拉、停止、熄屏再唤醒。以真实画面判断方向与自然感，不能只看日志或合成峰值。
4. 完成一次有依据的调整后保存候选；再进入人物结构阶段。

### 暂时没有手机反馈时

云端可以直接做阶段2的结构准备，不把手机等待当成全部工作的阻塞：

1. 逐项检查 structure.mjs、接触权重、人物mask与现有四图，画清可见体块/支撑/遮挡边界。
2. 为头颈和躯干建立可编辑的连接与独立旋转试验，保持原中性画面；先做主视角小范围，不直接拉大所有角度。
3. 为左右/俯仰生成统一角度扫描，列出真实出现的拉伸、空洞与遮挡问题。
4. 输出结构方案、实验实现和确有必要的素材缺口清单，单独提交；此时仍把手机裁剪与手感标成未验。

下一轮优先把这些工作作为一个有完整对照的结构节点交付，不为凑小版本只改一两个参数。
