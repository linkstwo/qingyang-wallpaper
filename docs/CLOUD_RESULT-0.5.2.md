# 云端增量 0.5.2 / versionCode 11

继承 fix/wallpaper-egl-lifecycle 的 86eaca6，工作分支 feature/cloud-framing-response。没有重建App、没有修改四原图/遮罩/背景/接触网格/包名/签名身份。用户已实际看到0.5.1人物和动态；本轮为进一步增强，尚未真机验收。

## 实际改动

- 构图：默认“舒展肩背”，可一键切回原近景，选择持久化并供壁纸引擎读取。针对长条屏，原图可见右边界从source x=868.8扩到1035，覆盖原先被裁掉的背部轮廓；背景空间由原有无人车间图填充，下缘渐隐。小幅连续转向沿用现有深度场，本轮未扩成大角度模型。
- 预览按手机长宽比嵌入，避免短预览面板看似完整、设为锁屏后又被放大的误导；实际系统是否额外缩放仍需真机观察。
- 回弹：保持视角跟随/躯干参数，局部弹簧阻尼0.50→0.36、频率3.2→2.85Hz，增强纯陀螺仪角加速度激励。缩小构图时补偿屏幕上可见的惯性位移；视角幅度与局部惯性仍是两条通道。
- 发梢：前侧松散发束的发根固定、末端权重递增，横向与纵向有各自弹簧和延迟；五官/眼镜不套用宽Gaussian发丝区。没有新增真3D/拆层PSD/Cubism动作模型。
- Android/WebGL共用scene.vert与scene.frag，导出脚本复制并逐字节核对；Java/JS物理通过同一输入轨迹校验。mesh.json的spring字段保留历史元数据，当前响应以Physics.java与response.mjs为准。
- 预览重新建立GL上下文时重建资源，暂停时停止GLSurfaceView；传感器输入向绘制线程提供原子快照。

1. Android SDK34 / JDK17 / Gradle8.7 assembleRelease成功。输出app-release-unsigned.apk，版本0.5.2/11。
2. 既有52项壁纸生命周期主机断言通过，原0.5.0反例仍在首帧断言失败。
3. 相同纯转动合成轨迹：局部回弹峰值0.5797→3.3130 source px，发梢横向0.8896→4.4611 px；停止后收敛，30/60/120fps固定步长轨迹一致。不是对所有实际动作或手机观感承诺5.7倍。
4. Java/JS响应对齐；真实MotionInput的轴向映射、停更清力、异常与乱序事件、帧快照及恒定倾斜保持检查通过。
5. 桌面Mesa离屏OpenGL实测编译/绘制同一套GLES2着色器。只摆发梢、保持背景填充一致时，所选脸部/手部接触ROI平均RGB变化为0；发梢ROI变化2.42/255。实际出图已目视查看并修正小构图头顶硬边，选用顶端对齐和下缘渐隐。
6. 原13资产/4对副本哈希、16384三角形与11个接触点、同源着色器导出校验通过。
7. 已生成18秒H.264对照视频（540×640，20fps）：桌面合成输入与离屏绘制，不是手机录屏。左右使用同一舒展构图，左原响应/右增强响应。

## 未验证与限制

- 云端浏览器二进制启动崩溃，未完成真实DOM交互/设置按钮的浏览器或Android界面走查；网页通过语法及模型检查，视觉由离屏GLES验证。
- 未连接手机，不启动模拟器：0.5.2真实锁屏构图、Q弹手感、系统裁切、反复唤醒、耗电/温升/性能待验。
- 看见更多背部来自扩大可见构图，不是新生成背部或完整三维观察。仍是主视角附近的连续2.5D。
- 线性加速度仍未直接加入Physics激励；本轮增强的是已有gyro角加速度通道，没有声称完成全姿态融合或无漂移360度视角。

## 给dsh的本机接续

云端当前没有AI桥或D盘连接，本轮未向桥发送新消息。请取本分支，在原项目基础上整合，沿用android-app/signing.properties和既有发布密钥，构建0.5.2/11；绝不换签名、不要求卸载0.5.1。云端unsigned包只是编译产物，不能直接安装。不要将旧故障main作为新起点。

先运行python3 tests/run_response.py、python3 tests/run_lifecycle.py及node android-app/tools/export_mesh.mjs --check。Android构建见docs/BUILD.md。Linux图像验收可用python3 tests/render_gles.py，需要Pillow及Mesa EGL。

真机验收：切舒展/近景→预览比例与锁屏是否对应→缓慢倾斜保持→快转/反向→停止收敛→发根/脸/手/图纸是否稳定→熄屏再恢复。若系统另施缩放，记录真实Surface尺寸再调整，不以日志首帧替代画面。
