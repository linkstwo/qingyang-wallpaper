## 问题与实现

原深度场虽有宽头部区域，但观看投影后仍对每个顶点分别软限幅，身体惯性权重也随位置变化。合成测试中，脸部四个检查点的两两距离相对原图最多改变8.9702源图像素。这是确定性几何指标，不是用户手机观感评价。

- structure.mjs新增headPlate参数：头部锚点(430,330)、深度116，y≤395保持刚性，395～565渐变连接颈肩。仍是手工拟合的图像空间区域，不是完整人体分区。
- 从现有三维投影的竖直参考轴提取平面方向；头部采用统一旋转和平移，避免逐顶点限幅造成五官/眼镜相互拉扯。该弱透视近似以形状稳定优先，不会凭空展示新的脸侧纹理。
- 头部身体惯性统一取锚点响应；颈部逐渐接回原躯干场，局部软组织不再把脸一起拉伸。发梢仍作为自由运动叠加，发根/脸部权重维持原约束。
- 网页CPU参考与共享GLSL同步；export_mesh已同步Android资产副本与结构元数据。深度/网格/接触权重二进制及原图均未变；Java物理/姿态/窗口映射未改。
