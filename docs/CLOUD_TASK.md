## 长期方向：像换角度观察角色的裸眼立体感

《查看项目任务》最新用户补充：晃动手机相当于调整观察角度，角色应呈现不同角度的自然外观，不光是胸部回弹。技术仍按已确定的2.5D主线逐步研究；“裸眼3D效果”不自动等于重启真3D建模路线。

必须分开两条通道：**姿态/方向决定观看角度**，**快速转动的角速度/角加速度决定局部惯性**。不能只加弹簧而把角度变化漏掉，也不能用整图平移或四图切换交差。现有网格只在主视角附近做有限表面形变，距离该长期效果还有差距。

## P0：0.5.0 真机锁屏黑屏

- 故障安装包在 evidence/baseline/qingyang-0.5.0.apk，源码在 android-app。先读 BLACK_SCREEN.md 的调用链定位，不要从图片重生成开始排查。
- 静态已确认：RenderLoop 从未调用 EglCore.create(surface)，frame 却因 !egl.hasSurface() 直接退出。应用预览用 GLSurfaceView 自建上下文，因此它成功不能证明服务成功。
- 建立/恢复正确的 EGL 和 renderer 生命周期，确认真实窗口首帧送达；检查失败日志、swap 返回值、Surface 丢失、双引擎/预览切换和屏幕唤醒。不要仅删掉 return 后在无上下文状态里画。
- 用户真机反馈优先于历史包说明。验收必须实际看到原人物图片：系统预览、桌面、亮屏锁屏；连续熄屏/唤醒后不再黑。没有手机时提供候选包与明确待真机验证项，不报全部完成。

## P1：陀螺仪驱动的 Q 弹

- 现有 SensorFeed 已注册陀螺仪，MotionInput 已算角速度/角加速度；Physics 已使用 alphaY/alphaX 激励。任务是改善实际输入/响应和手感，不是再叠一份注册。
- 姿态控制观看方向与快速动作激励分开；评估重力/姿态融合与陀螺仪的角色，保持倾斜时角度稳定，避免长时间纯积分漂移。不能把只有回弹激励称作完整的陀螺仪视角控制。
- 慢倾斜控制有限视角并保持；快晃/快转独立激励身体和胸部，先滞后、越过中点、回弹再衰减。保留现有用户认可的节奏，幅度/阻尼分开调，避免统一放大造成衣纹断裂。
- 记录坐标系、单位、时间戳和旋转映射。只旋转手机而倾斜差值很小时也应有响应；若启用线性加速度，注意目前 Physics 并未直接使用 ax/ay/az，避免把平移通道误报为已接入。
- 重复输入下频率、峰值和衰减可比较；停止后稳定，传感器停更/切换不保持假力。大输入限幅但不长期撞限位。

## P2：发梢来回摆

- 当前只有一个横向 hairX 弹簧、一个 Gaussian 碎发区域和固定0.35倍纵向偏移，并非分段发梢绑定。
- 对照主图手工标发根、自由中段和发梢；发根/发髻固定，越靠末端越自由。至少让可见的前侧长碎发有独立左右摆动、轻微纵向滞后与回弹。
- 与头部、身体频率/相位不同；头转以后发梢稍慢跟上。边缘遮挡要自然，避免背景拖影、锯齿、碎发脱离或脸/眼镜橡皮化。
- 不用生成替代人物或修改服装。必要拆层只处理运动需要的区域，保留原图和可回退版本。

## 顺序与交付

先 P0 单独提交并验证 → P1 输入/物理 → P2 发梢权重/视觉，各阶段提供前后对照、改动清单和验证边界。最后交付可编辑源码、可复现构建命令、候选 APK、实际图片/视频证据及未验证项。正式包签名在本地完成，不把私钥加入仓库或聊天。

四张参考原图都在 references/originals，先逐张查看，再决定如何借用结构。大角度/背面并非本轮必须完成，不承诺360度观察。

P0/P1/P2稳定后继续多角度结构研究：检查脸部轮廓、肩腰截面、头发和手臂的遮挡是否随视角合理变化；确定可实现的连续范围与需要补绘的局部形状。四图姿势不完全一致，不能直接当作严格多视角重建输入。本包只确认这四张已保存原图，不能声称其它角度素材都已齐全。
