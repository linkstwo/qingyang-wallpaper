# 0.5.8胸部/左轮廓反馈修正

用户报告胸部不自然、左边有未消除的原曲线。保持原人物RGB和Q弹弹簧计算，先在原0.5.8轨迹下复现。

静态底图清除与人物运动共用缩进的颜色分割边界，漏掉了浅色衣料抗锯齿像素；只扩大底图清除又会在静止时露出暗圈。本次将运动覆盖放R通道、源轮廓清除放G通道；清除覆盖原浅色边缘，但其边界处于运动层完全不透明的范围内。源图不被重画。实际生产GLES的胸部静止区域与未清除参考对比RGB均值差为0，浅色旧轮廓检查通过。

单一宽高斯运动场改成两个平滑材料瓣，在领口/胸廓附着区渐进归零，避免整个胸口与衣料一起被同一个峰拖动。Q弹频率、阻尼和输入响应未改。现有极端几何/CPU-GLES检查重新通过；不把这些云端结果当成用户已经认可观感。

验证入口：tests/contour-regression.py、reading-subject-regression.mjs、render_gles.py、check_projection_gles.py、export_mesh.mjs --check、scripts/verify_assets.py。

按用户授权，此修正离线验证后直接继续S2，不在阶段交界等待确认。S1的其他图像配准/真机验收仍保留为未完成。
