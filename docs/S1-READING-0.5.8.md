## 本次实际完成

- 使用用户授权的新阅读照片1000030775.png，1152×1536。源图SHA-256：cc43f133c865b272f06cdff0d35086fae5b668100a70df09cc5cc1d0301eb411。上传文件名为png、实际JPEG编码，参考与运行副本保留完全相同的原始字节，不重画人物；四张历史原图保留不动。
- 重新标定头脸、胸/躯干、发梢包络、远侧手臂与持纸手、图纸/坐姿支撑；重新导出遮罩、16384个人物三角形、接触权重、深度和前景网格。头脸采用共同刚性代理，发梢有独立延迟。细发用人工包络近似，并非逐根发丝模拟。
- 新胸部源图中心为(725,755)，默认映射至整块锁屏中心。常见长屏默认原图画面高度约77%—78%，60%是设备比例相关的缩小下限；提供主体突出/保留更多/近景起点、双指缩放、单指移动、一键居中、草稿取消与显式保存。
- 恢复上一轮生成的空车间背景，用于人物移动后揭露及上下空间承接。移除大块模糊和渐黑背景处理；背景仍为派生补全，不是真实多机位场景重建。
- 保留0.5.7已使用的Q弹计算与父子相对响应，不统一放大所有位移。针对新姿势，把远臂约束限制到可见区并加宽过渡，避免与胸部柔性区域交叠时挤折。
- 主界面以满屏人物预览和调整构图/设为壁纸两个主要操作为主；详细选项收起。取景面板默认收起，支持动态试看、保存并设置和未保存草稿处理。
- 冻结编辑时只在取景改变时重绘；动态预览随vsync和传感器唤醒，静止后降低更新，暂停时停传感器。预览允许保留EGL上下文，取景变更只更新变换，不再重复查询屏幕或重建资产。壁纸服务的既有生命周期修复保留。
