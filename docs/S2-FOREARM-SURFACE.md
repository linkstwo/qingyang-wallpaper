# S2 前臂来源边界与推断厚度实验

2026-10-26，用户授权连续开发，fence6。源码与验证保存后继续推进，不因这个子项停在阶段边界。

原图实际像素复核：旧最大拟合残差(525.55,953.77)是可见前臂。原生产深度22.17与闭合代理前部约180不一致。这里的180仍是推断深度，不能称为实测人体。旧肘点(635,920)被袖子遮住，observed已纠正为false；不采用落在胸前衣服上的替代肘点(545,870)。来源边界证据见validation/s2-forearm-source-boundary.jpg。

直接把前臂厚度写入旧单片深度场的实验失败：yaw0.08/pitch0.04时最小有符号面积比-0.00546。已恢复生产structure.mjs与character_depth.bin；tests/forearm-volume-negative-control.mjs保留可复现拒绝对照。

当前研究实现按原图皮肤边界分离前臂表面。切割保留源图覆盖，重连合法内部对角线改善瘦三角形，禁止改变材质边界和源图坐标。源图面积差0.00050px²；约248.7万组相机/旧材料运动扫描，最小面积比0.2433；中性投影误差<2.3e-13px。手腕仍贴纸面，衣服/背景的目标深度不随前臂实验改变。质量重连独立夹具验证边界/面积不变、无重复面，最小角0.0588->0.2187rad。

工作台新增“前臂分层厚度实验”开关，默认关闭。实际WebGL新表面参与斜视显示，后壳开关中性帧缓冲严格全通道差异0；但实验与默认前景的中性截图仍有29个>2差异像素、最大51，不能声称中性图像完全相同。一次固定中性clipW的试验没有解决差异，已撤销，没有为通过而放宽断言。后续须对齐分层边界的来源采样与栅格覆盖。

骨骼大幅组合扫描另记录在s2-forearm-pose.json。整幅前景包含既有纸边/背景过渡表面，出现负面积比，fullFrontAccepted=false。新前臂自身的结果单列；组件验证不等于整幅前景通过。前后表面未焊接，背图置信度0，S2仍未验收；生产角度/Q弹/RGB/包名/签名和0.5.9 APK不变。
