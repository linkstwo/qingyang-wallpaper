# 同一世界平面的深度与网格细分无关

发现旧clipZ=-worldZ/1000*clipW不是世界坐标的仿射齐次变换；透视除法后的深度在三角形内部依赖所用的细分。它与已经用离屏呈现解决的16个MSAA残留是不同问题，不能混为同一原因。

现在clipZ=(4250-14*worldZ)/17250，clipW=(2300-worldZ)/2300，近世界Z+1000、远世界Z-2000分别映射到NDC-1/+1。世界+Z朝向观察者。XY投影、图像RGB、构图与Q弹参数不变。sceneModel版本2、structure版本8、导出报告带深度约定；Android资产与原型scene.vert字节同步，调试结构/观测表面也使用同一约定。

实际GLES在同一倾斜纸平面上比较粗/细网格，3个相机姿态每个约27万内部像素。正确式最大窗口深度差2.3842e-7；旧二次式最大0.00129867，是测试必须拒绝的负对照。测试编码gl_FragCoord时显式提升到highp，避免片元默认精度导致24位编码溢出。

5项深度顺序/两种绘制顺序、1440 GPU关键点、脸/接触/发梢实际渲染、7293场景约束、分层扫描、资产一致性和52生命周期检查通过。桌面浏览器默认离屏路径仍全通道0差异；直接4xMSAA路径仍有旧16像素残留，单独保留为诊断对照。

这是当前生产着色器源代码修正，尚未构建新候选、未在手机验证。S2连续隐藏材料和前后曲面连接仍未验收；0.5.9是旧的已签名公开候选，不声称包含此修正。保存后继续推进连接与来源，不在该检查点结束运行。
