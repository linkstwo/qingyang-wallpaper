# 给云端的开始指令

请接手本次上传的轻漾仓库/ZIP，先读根AGENTS.md和docs/CLOUD_TASK.md，再逐张查看references/originals里的四张原图。

当前0.5.0在iQOO Z9 Turbo锁屏黑屏。先按docs/BLACK_SCREEN.md修WallpaperService的EGL首建与Surface重建，验证实际人物画面。然后保持已有律动风格，改善陀螺仪的Q弹与衰减，再手工做发根固定、发梢能来回摆的权重/延迟。保留原脸、衣服、坐姿、手与图纸接触，只做2.5D。

不要再花一轮仅复述计划或重建App。直接检查现有代码、逐阶段实现和验证；云端无法连手机时明确标注候选包待真机锁屏验收。正式签名私钥留本地，云端输出debug/unsigned包即可。

长期方向是手机转动相当于换观察角度，人物轮廓、遮挡和身体结构随角度自然变化。把姿态控制视角与快速转动触发局部惯性分开；当前有限网格形变不等于该目标已经完成，P0/P1/P2稳定后继续多角度结构研究。

此交接提交保留故障Java基线：它是可复现起点，不是修复包。其他会话若提供修复补丁，请对照该基线单独审查与验证，不直接把“另一会话说完成”当成验收。
