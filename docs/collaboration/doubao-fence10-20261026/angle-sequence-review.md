## 关键发现：front-variant 与 main-reading-v2 是同构图

像素对比证据：
- front-variant: 1086x1448
- main-reading-v2: 1152x1536
- resize到同尺寸后 mean pixel diff = 1.51 / 255（几乎为零）
- max pixel diff = 52（仅边缘/噪点差异）
- 并排对比图：人物位置、姿势、纸的位置、背景、光照几乎完全一致

结论：**两图是同视角的不同分辨率版本，不是两个不同角度。**
序列A（1→2）应标记为**同视角重复候选**，不能声称获得连续角度变化。

## 候选序列与逐对分析

### 序列A（同视角重复）：1 → 2

**front-variant → main-reading-v2**

| 维度 | 差异 |
|---|---|
| 手臂 | 完全一致 |
| 头 | 完全一致 |
| 服装 | 一致 |
| 朝向 | 无变化（同构图） |
| 尺寸 | 不同：1086x1448 vs 1152x1536 |

- **能用部位**：胸前正面、右肩、右臂、左侧脸颊、部分左肩
- **不能接的部位**：左臂（撑后完全不可见）、背部、后脑勺
- **连续性判断**：**不是角度序列，是同视角重复。不能作为连续显露的证据。**

### 序列B（正面偏左 → 右侧面）：3 → 4

**main-front-three-quarter → side-reference**

| 维度 | 差异 |
|---|---|
| 手臂 | 不同：3是双手在胸前纸上，4是双手在桌上纸上且身体前倾 |
| 头 | 不同：3脸朝右下，4脸朝右 |
| 服装 | 一致 |
| 朝向变化 | 大：从正面偏左到完全右侧面 |
| 姿势 | 不同：3是端坐，4是前倾坐姿 |

- **能用部位**：胸前区域（3）、右侧身体（4）
- **不能接的部位**：正面到侧面的中间过渡区域完全没有图
- **连续性判断**：朝向跳变大，姿势也不同，不能形成连贯显露。

### 序列C（右侧面 → 背面）：4 → 5

**side-reference → back-reference**

| 维度 | 差异 |
|---|---|
| 手臂 | 不同：4双手在桌上，5只有右手可见且位置不同 |
| 头 | 不同：4低头看纸脸朝右，5脸转向右侧 |
| 服装 | 一致 |
| 朝向变化 | 极大：从右侧面到背面 |
| 姿势 | 不同：4是前倾坐姿，5是正对桌子坐姿 |

- **能用部位**：右侧身体（4）、背部（5）
- **不能接的部位**：侧面到背面的过渡完全断裂
- **连续性判断**：朝向跳变极大，姿势差异大，完全不能连续。

## 全局结论

1. **front-variant 和 main-reading-v2 是同构图不同分辨率**，不是两个角度。本地5张图实际只有4个不同视角。
2. **没有任何一对能形成"角度逐步变化、姿势相近"的连贯序列**。
3. **序列B和C的朝向跳变都很大**，中间完全没有过渡图。
4. **归档库还有6张额外构图没有本地副本**，可能填补中间朝向，但本次不下载、不评估。
5. **所有图都是坐姿、低头看纸**，姿势变化范围很窄。
6. **不能虚报"已完成角度序列"**。
