## 二、素材事实（今晚确认，豆包审查为底）

- 本地 5 张图 = **4 个真实视角**：正面偏右（front-variant）→ 正面偏左（main-front-three-quarter）→ 右侧面（side）→ 背面（back）。front-variant 与 main-reading-v2 同构图不同分辨率（像素 diff 1.51/255）。
- **逐对对齐质量（人工目测锚点，无标定）**：fv→mf 平均残差 ~68px（姿势最接近，可用于粗过渡）；mf→sd、sd→bk 姿势不同，仅语义锚点对齐，只支持整档切换 + 遮挡标注。
- 档位间过渡 = 对齐插值（**不是真实 3D**）；档位处 = 真实原图。
- 素材缺口不变：无同瞬间多机位、无中间角度、无深度代理、背面细节不对应。
