# 轻漾 2.5D 角色编辑器 · 用户手册

> 3 分钟上手；详细边界见 `ACCEPTANCE.md`，开发者文档见 `README.md`。

## 一、快速开始

```bash
node editor/server.mjs        # 启动（默认 http://127.0.0.1:8644/）
```

浏览器打开后自动载入示范工程（主图 + 网格 + 蒙版 + 背景，16384 三角形）。
若启动时提示"检测到自动备份"，点【恢复】可回到上次编辑状态。

## 二、界面导览

| 区域 | 内容 |
|---|---|
| 顶栏 | 打开/保存工程、撤销/重做（含计数）、帮助 |
| 左栏上 | 素材导入（PNG/JPG，可作蒙版）、图层树（显示开关）、视角参考（4 张真实视角对照）、输入轨迹录制 |
| 左栏下 | 连续视角滑杆、手机安全框（4 画幅）、构图对照 |
| 中央画布 | WebGL 实时渲染 + 网格/控制点/接触区叠加 |
| 右栏 | 选中图层的全部参数（四组弹簧、位移上限、激发增益、区域场、接触区、网格编辑） |
| 底栏 | 工具切换（选择/多边形/画笔/擦除）、演示播放/单步/复位、帧率与位移读数 |
| 状态栏 | 每一步操作的回执（所有动作都有确认文字） |

## 三、编辑操作

### 网格顶点（形变基线）
- 工具"选择/拖点"：靠近控制点出现黄色圈与顶点信息（编号 + pin 值）→ 拖拽。
- 红点 = 接触固定区（pin=1）：拖不动属正常（壁纸里手/图纸/坐姿必须钉死）。
- 右栏【检查网格质量】：拖完跑一次，防止翻转/退化。

### 蒙版与接触固定区
- "多边形"工具：画布点 3+ 下、双击闭合。目标二选一：
  - **蒙版多边形**：填入当前图层蒙版（白=人物）。
  - **接触固定区**：新增一块 pin 区域（编辑器立即重算权重，渲染同步）。
- "蒙版画笔/擦除"：半径可调；画错 Ctrl+Z。

### 参数（右栏，改动即生效并入撤销栈）
- **弹簧**（body/chest/hair/hairTip 四组独立）：频率=回弹速度、阻尼=衰减、限幅=最大位移比例。
- **位移上限**：躯干/胸部/头发/发梢的像素上限。
- **激发增益**：倾斜/晃动激励各通道的强度。
- **区域场**：head/neck/chest/shoulder/torso/cheek/hairRoot/hairTip 八个区域的中心/半径/深度/惯性。

### 运动预览与输入
- ▶ 播放 18 秒演示轨迹；⏭ 单步逐帧观察；⟲ 复位。
- 直接移动鼠标/手指 = 手动输入（保持位置即保持视角）。
- **输入轨迹**：⏺ 开始录制 → 画布上做动作 → 再点一次保存；下拉选轨迹 ↻ 回放；📊 输出 30/60/120fps 对比 JSON。
- **连续视角滑杆**：拖动等效手机缓慢转动；【与静态基线对比】归零。

### 手机构图
- 选画幅（9:20 / 9:19.5 / 16:9 / 1:1）→ 黄色虚线框即手机窗口，锚点绿=在窗内、红=被切。
- 【输出可见性对照数据】导出三档偏移的 JSON（含每个视角脸/肩/腰是否可见）。
- 多视角构图对照表在页面下方：结论=固定窗口无法四视角全保，推荐跟移窗口（Android 已内置）。

## 四、工程文件与数据安全

- **Ctrl+S** 下载 `.qingyang.json`（唯一完整备份；格式 qingyang-editor-project v1，带 schema 校验）。
- **自动保存**：编辑约 3 秒后自动快照到浏览器；重开页面出现黄色恢复条，点【恢复】即回。清除浏览器站点数据会丢自动备份。
- 打开工程：📂 打开工程 → 选择文件；schema 校验失败会拒绝并给出原因。

## 五、导出到 Android 壁纸

```bash
node editor/export/export-android-assets.mjs <工程.qingyang.json> <输出目录>
# 输出：character_mesh.bin / character_pins.bin / foreground_mesh.bin /
#       original/mask/background.png / qingyang-params.json（渲染参数）/ 报告
```

- 未编辑工程导出的 bins 与 `android-app/app/src/main/assets/` 逐字节一致（`--check` 可验）。
- 把导出的 `qingyang-params.json` 与 bins/png 放进 `android-app/app/src/main/assets/` 重新构建 APK，手机壁纸即按编辑器参数运动。
- 也可直接在手机 App 的【⚙ 取景参数】里调窗口基准与跟移幅度（即时保存，重开生效）。

## 六、故障排查

| 现象 | 处理 |
|---|---|
| 页面黑屏/加载中不动 | 确认 `node editor/server.mjs` 在跑；刷新页面；换无痕窗口 |
| 拖点没反应 | 确认工具是"选择/拖点"、目标图层是"人物" |
| 导出报"找不到纹理" | 工程引用的图片文件被移动了——把图片放到工程文件旁或恢复仓库结构 |
| Android 壁纸黑屏 | 用本分支 APK（含 EGL 首建修复）；main 分支旧包有此 bug |
| 参数改了手机没变化 | 确认 params.json 已放进 assets 且重新构建 APK |

## 七、已知边界（诚实清单）

- 连续视角真实范围 ±0.35（超出为同一曲面滑移，不生成新轮廓）
- 4 张参考图姿态不完全一致，无法直接混合成全角度模型
- 自动保存依赖浏览器存储；完整备份请 Ctrl+S
- 真机（iQOO）帧率/耗电/锁屏观感未测
