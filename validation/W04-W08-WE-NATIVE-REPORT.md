# W04-W08 WE原生路线验证报告

## W04 构图与控制
### 构图参数
- 正交投影：1152×1536（竖屏比例，适配手机）
- 相机视差：0.08，延迟0.12s
- 清理色：深棕黑(0.05, 0.04, 0.035)
- 对齐：center，origin在画面中心(576, 768)

### 用户控制（3项）
1. **局部回弹强度** - slider 0~1.5，默认1
2. **演示开关** - 18秒慢倾斜/快晃/停止循环，默认关
3. **轻微呼吸** - 微弱起伏动画，默认开

### 效果管线
- 3个渲染pass：状态更新→反馈缓冲→最终变形
- 双RG16F反馈缓冲（9×1）保存9个弹簧状态
- 独立身体/胸部/发梢弹簧
